# Architecture Decision Records

This folder holds Architecture Decision Records (ADRs) for `ttrpg_session` — short
documents capturing significant architectural decisions, their context, and their
consequences.

## Format

Each ADR is a numbered Markdown file (`NNNN-short-title.md`) using a simple format:

- **Title** — `ADR NNNN: <decision>`
- **Status** — Proposed | Accepted | Superseded by ADR-XXXX | Deprecated
- **Context** — the forces and constraints that prompted the decision
- **Decision** — what we decided to do
- **Consequences** — the resulting trade-offs, both good and bad
